# Componente terțe

Aplicația include următoarele componente open-source, fiecare sub licența proprie.

| Componentă | Folosită pentru | Licență |
|---|---|---|
| [Python](https://www.python.org/) | limbajul aplicației | PSF License |
| [OpenCV](https://opencv.org/) (`opencv-python`) | detecție, procesare video | Apache 2.0 |
| [NumPy](https://numpy.org/) | calcule pe imagini | BSD 3-Clause |
| [Pillow](https://python-pillow.org/) | randarea textului și a imaginilor | MIT-CMU (HPND) |
| [Tcl/Tk](https://www.tcl.tk/) | interfața grafică | Tcl/Tk License (BSD-style) |
| [PyInstaller](https://pyinstaller.org/) | împachetarea ca `.exe` | GPL 2.0 cu excepție pentru bootloader (permite distribuirea aplicațiilor comerciale) |
| [Hanken Grotesk](https://fonts.google.com/specimen/Hanken+Grotesk) | fontul textului de pe video | SIL Open Font License 1.1, textul complet în [licenses/OFL-HankenGrotesk.txt](licenses/OFL-HankenGrotesk.txt) |
